# MineTunnel Control Center

MineTunnel Control Center é uma aplicação front-end de página única para visualizar mundos de Minecraft compartilhados por túneis e acompanhar a infraestrutura de conexão. A listagem principal apresentará pelo menos dez mundos com nome, descrição, versão, quantidade de jogadores, status e latência, enquanto a listagem secundária mostrará os relays disponíveis com região, capacidade e estado operacional. O projeto é uma demonstração acadêmica da interface do MineTunnel e será desenvolvido progressivamente com React, TypeScript e Tailwind CSS.
